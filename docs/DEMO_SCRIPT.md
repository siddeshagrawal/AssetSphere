# 6-Minute Demo Script

## 0:00–0:40 — The Story

Open the landing page. Lead with: **“Your knowledge changes. AssetSphere understands what changed.”** Briefly point out secure workspaces, multi-format assets, grounded retrieval, and Evolution Intelligence. Register or sign in.

## 0:40–1:20 — Workspace Home

Open the authenticated workspace overview. Show real recent assets, processing states, quota usage, and activity. Emphasize that every route is workspace-authorized and every displayed value comes from backend data.

## 1:20–2:00 — Upload and Reliability

Upload a supported document through the dropzone. Point out progress and honest async processing states. Explain that the upload transaction writes an outbox event; Kafka processing has retries/DLT, Redis locking, bounded extraction, and idempotent replay protection.

## 2:00–2:40 — Search and Intelligence

Run Hybrid Search using language present in the document. Contrast lexical exact matches with semantic meaning, then download the exact returned version. Open the asset and generate exact-version AI Intelligence; show summary, key points, and tags.

## 2:40–3:40 — Versioning and Flagship Moment

Upload Version 2 of the same logical asset. Show preserved history and exact-version downloads. Select Version 1 and Version 2, then run Evolution Intelligence. Explain that only the two authorized bounded texts are sent on demand.

## 3:40–4:30 — Grounded Ask

Ask a workspace question. Open the returned citations and explain deterministic source IDs, trusted application metadata, unknown-citation removal, and the no-evidence path that avoids an AI call.

## 4:30–5:10 — Activity and SaaS Controls

Return to Overview and show the audit timeline. Open Billing to show the real FREE plan, current usage, remaining quotas, and server-side enforcement before expensive operations.

## 5:10–5:40 — Verified Upgrade

Start the configured checkout. Stripe uses hosted recurring checkout; explicit local-dev mode uses the MY/TUTOR demo flow. Explain that price is backend-owned and browser completion cannot activate PRO without verified provider confirmation.

## 5:40–6:00 — Close

Summarize: version-aware knowledge, grounded AI, production-minded reliability, and a clean modular architecture. End on the Evolution Intelligence statement.

## Optional Reliability Proof

With DLT operations explicitly enabled, trigger a known failure, correct the dependency, and replay it. AssetSphere resets the failed asset/semantic state before republishing the unchanged event identity. Mark this as manual verification unless the full Kafka scenario has been run.
